# Introduction to Variables in Algorithms



##### 1.  Definition of variables

```{admonition} Variable
:class: tip

A variable in an algorithm is a symbolic name that represents a memory location where data can be stored, modified, and retrieved during execution. Variables are essential for storing values that change throughout the execution of an algorithm.
```


##### 2. Key Characteristics of Variables


```{admonition} Key Characteristics of Variables
:class: tip

The key characteristics of variables in algorithms are as follows:

- Name: A unique identifier for the variable.

- Data Type: Defines the type of value the variable can hold

- Value: The actual data stored in the variable.

- Memory Location: The address where the value is stored in memory.
```

**Example**

```
Begin  
   X ← 10  
   Y ← X + 5  
   Output Y  
End
```

```
Begin  
   X ← 10  
   Name ← "Ahmed"  
   Output Name, "has", X, "apples."  
End
```

##### 3. Arithmetic Operators

###### 3.1. Addition 

$$
a + b
$$

Adds two values together.  

###### 3.2. Subtraction

$$
a - b
$$

Subtracts one value from another.  

###### 3.3. Multiplication

$$
a \times b \quad \text{or} \quad a \cdot b
$$

Multiplies two values together.  

###### 3.4. Division

$$
\frac{a}{b}
$$

Divides one value by another.  

###### 3.5. Modulus

$$
a \mod b
$$

Returns the remainder after dividing a by b.  

Example: $ 10 \mod 3 = 1 $

###### 3.6. Exponentiation

$$
a^b
$$

Raises \(a\) to the power of \(b\).
