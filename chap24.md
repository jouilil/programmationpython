# PRACTICE EXERCISES

##### EXERCISE 1

```{admonition} EXERCISE

Given the following variable assignments:

- 2value ← 100

- total amount ← 50

- first_name ← "Samira"

- is_active ← True

- user-Data ← "Info"

- userAge ← 30

- for ← 5

- @status ← "Online"

- score1 ← 85

- Age$ ← 40

Which of these variable names are valid or invalid according to variable naming conventions? For each invalid variable, provide the corrected name.

```
